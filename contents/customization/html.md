---
title: "HTML Customization"
description: "Customize the HTML structure of your documentation."
---

Adding **custom HTML** to your documentation site is possible via Markdown. Basically, you can include raw HTML tags directly within your Markdown files, once built, the HTML will be rendered as part of your documentation.

### Allow HTML Tags
By default, Booyaka allows a set of common HTML tags. If you need to allow additional tags or attributes, you can configure this in your Booyaka configuration file.
