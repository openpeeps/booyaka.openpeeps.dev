title: "Custom CSS"
description: "Adding custom CSS to style your documentation is simple and straightforward!"
---

Adding **custom CSS** your documentation site is as simple as creating a CSS file and linking it in your configuration.

Booyaka is automatically looking for a file named `style.css` inside the `docs/assets/` folder. If it finds it, it will include it in the generated HTML files. That's it!
