While you can create and manage your documentation using any text editor, it is often more convenient to use the built-in content editor provided by Booyaka.

The built-in content editor that allows you to create and manage your documentation directly from your browser. This editor provides a user-friendly interface for writing, formatting, and organizing your content. Based on the popular **TipTap editor**, it offers a rich set of features to enhance your documentation experience.

## Enable the Content Editor
To enable the inline content editor, start your Booyaka site with the `--edit` flag:

```
booyaka run --port:8000 --edit
```

Once the server is running, open your web browser and navigate to `http://localhost:8000`. You will see an "**Edit**" button in the top-right corner of the page. Click this button to access the content editor.
