# Page Ordering
You can control the order of documents in the sidebar by prefixing filenames with numbers. For example:

```
01-Introduction.md
02-Getting-Started.md
03-Advanced-Topics.md
```

The same applies to folders:

```
01-Basics/
02-Intermediate/
03-Advanced/
```

This way, you can ensure that your documentation is presented in a logical and easy-to-follow sequence. Files and folders without a numeric prefix will be sorted alphabetically after the numbered items.
